# سیستم مدیریت کتابخانه

نسخهٔ دسکتاپ فارسی و راست‌به‌چپ با WPF، ‎.NET 8، Entity Framework Core و SQLite؛ مناسب استفادهٔ تک‌کاربره روی ویندوز.

## پیش‌نیاز و اجرا
- Windows 10/11 و ‎.NET 8 SDK.
- در اولین اجرا، `setup_and_run.bat` را اجرا کنید.
- اجرای دستی از پوشهٔ دارای فایل `LibraryManager.csproj`:
  ```powershell
  dotnet restore
  dotnet build
  dotnet run
  ```
- به SQL Server یا SQL Server LocalDB نیاز نیست.
- فایل پایگاه داده در `Data/LibraryManager.db` کنار فایل اجرایی برنامه ساخته می‌شود. در اجرای Debug، معمولاً در `bin/Debug/net8.0-windows/Data/LibraryManager.db` قرار دارد.

## پشتیبان‌گیری
از صفحهٔ «پشتیبان‌گیری» نسخه تهیه کنید. فایل‌های پشتیبان SQLite با پسوند `.bak` در پوشهٔ `Backups` کنار فایل اجرایی ذخیره می‌شوند. برای بازیابی، برنامه را ببندید، از فایل دیتابیس فعلی نسخهٔ پشتیبان بگیرید و فایل `.bak` موردنظر را به `Data/LibraryManager.db` منتقل کنید.

## نکات نسخهٔ فعلی
- برنامه از `EnsureCreated()` استفاده می‌کند؛ در پروژه فعلاً Migrationهای EF Core تعریف نشده‌اند. تغییرات آینده در ساختار دیتابیس باید با راهبرد Migration مدیریت شوند.
- تاریخ‌ها در پایگاه داده به‌صورت `DateTime` ذخیره می‌شوند و تبدیل تقویم شمسی در این نسخه پیاده‌سازی نشده است.
- فیلد تصویر جلد برای نسخهٔ آینده رزرو شده است.
- خروجی PDF با QuestPDF تولید می‌شود؛ برای نمایش مناسب متن فارسی، فونت سازگار مانند Tahoma باید روی سیستم موجود باشد.
